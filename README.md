# CoRu
CMS CoRu — мини-CMS v1.0.8 на PHP 8.3+ с Twig-шаблонами и файловым хранением контента в HTML и YAML. 
В ней есть Админ-панель с ролями пользователей, управлением страницами, категориями, темами и медиа файлами. 
Модули по умолчанию:  магазин с корзиной и заказами, SMTP-почты и чата.
Установка: Распаковать архив в папке сайта и запустить, при первом запуске создается Администратор сайта.
Не совместима с GRAV.
