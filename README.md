EN: CMS CoRu is a mini-CMS v1.0.8 in PHP 8.3 with Twig templates and file storage of content in HTML and YAML. 
Russian and English with translation from the amin panel.
An admin panel with user roles, page management, categories, themes, and media files. 
Default modules: a product page (so far one) with a shopping cart, SMTP mail, and chat.
Installation: Unpack the archive in the site folder and run it. The first time you run it, the Site Administrator is created.
Not compatible with GRAV.
Coming soon: site monitoring, questionnaires with surveys. Demo site with access to the Admin panel: https://coru.site2days.ru/
